# 프로젝트 제안서 — TimeFit

## 📌 기본 정보

| 항목 | 내용 |
|---|---|
| 프로젝트명 | **TimeFit** — 시간표 자동 조합 도우미 |
| 개요 | 듣고 싶은 과목과 분반을 입력하면, 시간이 겹치지 않는 시간표 조합을 모두 찾아 보여 주는 웹앱 |
| 예상 결과물 | GitHub Pages로 배포된 웹앱 (PC·모바일 브라우저에서 바로 사용, 설치·로그인 불필요) |

### 동기 (Why)

- 수강신청 전에 듣고 싶은 과목과 분반을 놓고 시간이 겹치지 않는 조합을 손으로 맞춰 본다. 과목이 5~6개, 과목마다 분반이 2~4개만 되어도 경우의 수가 수백 가지라 빠뜨리거나 실수하기 쉽다.
- "오전 9시 수업은 피하고 싶다", "금요일은 공강이었으면 좋겠다" 같은 조건까지 따지면 머릿속 계산으로는 원하는 시간표를 찾기 어렵다.
- 학교 포털은 과목 검색과 신청만 제공하고, 여러 후보 조합을 비교하는 기능은 없다. 그래서 엑셀이나 종이에 시간표를 여러 장 그려 비교하게 된다.

## 🛠 기술 스택

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| Frontend | HTML, CSS, JavaScript | 별도 프레임워크 없이 기본 웹 기술만으로 구현할 수 있는 규모 |
| Backend | 없음 | 계산을 모두 브라우저에서 처리하므로 서버가 필요 없음 |
| Database | 브라우저 localStorage | 입력한 과목 목록만 저장하면 되므로 DB 대신 브라우저 저장소 사용 |
| Deployment | GitHub Pages | 무료, GitHub Actions로 자동 배포 가능 |
| Test | Jest | JavaScript 테스트 도구, `npm test -- --coverage`로 커버리지 측정 |
| CI/CD | GitHub Actions | 테스트·배포 자동화, DORA 지표 수집 |

조합을 찾는 핵심 로직은 **재귀 백트래킹**으로 구현한다. 과목마다 분반을 하나씩 골라 나가다가, 시간이 겹치는 순간 그 선택은 버리고 다른 분반을 시도한다.

## 🎯 주요 기능

1. **과목·분반 입력** — 과목명, 학점, 분반별 요일·교시를 입력하고 브라우저에 저장한다.
2. **충돌 없는 조합 생성** — 과목마다 분반을 하나씩 고른 조합 중 시간이 겹치지 않는 것만 찾아 시간표 격자로 보여 준다.
3. **조건으로 정렬** — 공강 요일, 오전 수업 회피 등 원하는 조건에 맞는 순서로 조합을 정렬해 비교한다.
