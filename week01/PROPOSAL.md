# 프로젝트 제안서

## 프로젝트명

**TimeFit** — 시간표 자동 조합 도우미

## 문제정의

- 수강신청 전 학생들은 듣고 싶은 과목과 분반을 놓고 시간이 겹치지 않는 조합을 손으로 맞춰 본다. 과목이 5~6개, 과목마다 분반이 2~4개만 되어도 경우의 수가 수백 가지라 빠뜨리거나 실수하기 쉽다.
- "오전 9시 수업은 피하고 싶다", "금요일은 공강이었으면 좋겠다", "강의실 이동이 짧았으면 좋겠다" 같은 조건까지 따지면 머릿속 계산으로는 사실상 최적의 시간표를 찾을 수 없다.
- 학교 포털은 과목 검색과 신청만 제공하고, 여러 후보 조합을 비교하는 기능은 없다. 학생들은 엑셀이나 종이에 시간표를 여러 장 그려 비교한다.

**목표**: 듣고 싶은 과목과 분반, 원하는 조건을 입력하면 시간이 겹치지 않는 시간표 조합을 모두 찾아 선호도 순으로 보여 주는 웹앱을 만든다. 로그인이나 서버 없이 브라우저만으로 동작해 누구나 바로 쓸 수 있게 한다.

## 핵심 기능 3개

1. **과목·분반 입력** — 과목명, 분반, 요일·교시, 강의실을 직접 입력하거나 CSV로 한 번에 불러온다. 입력한 목록은 브라우저에 저장된다.
2. **충돌 없는 조합 생성** — 과목별로 분반 하나씩을 고른 모든 조합 중 시간이 겹치지 않는 것만 찾아낸다. 필수 과목과 선택 과목을 구분해, 학점 범위 안에서 가능한 조합을 만든다.
3. **조건 기반 정렬·비교** — 공강 요일, 오전 수업 회피, 연강 최소화 등 조건에 점수를 매겨 조합을 정렬하고, 후보 시간표를 나란히 비교한 뒤 이미지로 저장하거나 링크로 공유한다.

## 기술 스택

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| 프론트엔드 | TypeScript, Vite, 바닐라 DOM | 빌드가 빠르고 정적 파일로 배포 가능 |
| 조합 엔진 | TypeScript 모듈 (UI와 분리) | 단위 테스트와 npm 패키지 배포가 쉬움 |
| 저장 | 브라우저 localStorage, URL 공유 | 서버·로그인 없이 동작 |
| 테스트 | Vitest, Playwright | 조합 로직 단위 테스트, 화면 E2E 테스트 |
| CI/CD | GitHub Actions | 테스트·빌드·배포 자동화, DORA 지표 수집 |
| 호스팅 | GitHub Pages | 무료, 저장소와 같은 곳에서 배포 이력 관리 |
| 계획·추적 | GitHub Issues / Projects / Milestones | 백로그와 스프린트를 코드와 같은 곳에서 관리 |

## 성공 기준

- 과목 6개, 과목당 분반 4개(4,096가지) 입력에서 충돌 없는 조합을 1초 안에 모두 찾는다.
- 13주차 실험에서 수강생 20명 이상이 실제로 시간표를 만들어 보고, 그중 절반 이상이 "다시 쓰겠다"고 답한다.
